# TewPvP Nova Client

Original Fabric client-side PvP/FPS UI for **Minecraft Java 1.21.11**.

## Nova update
- New animated lobby with a dedicated **CLIENT MENU** button.
- Responsive layout for normal Minecraft GUI sizes and smaller/mobile-style GUI scales.
- More HUD, performance, animation and cosmetic test options.
- Modrinth-powered Mod Center with search, pagination, project names, descriptions, download counts and live thumbnails.
- Modrinth-powered Resource Pack Center with search, pagination, names, descriptions, download counts and live thumbnails.
- Compatible files are resolved for Minecraft 1.21.11 instead of relying on a tiny hard-coded list.
- Resource packs reload without restarting when supported by Minecraft.
- Fabric mods use the normal mods folder and require a restart to load.
- Schematic and diagnostics data use the project-local .tewpvp-nova folder.
- New artifact/project name: tewpvp-nova-client.
- Original UI/code only; no Lunar/Badlion proprietary assets or code.

## Build
Java 21 + Gradle + Fabric Loom for Minecraft 1.21.11.

The release JAR is build/libs/tewpvp-nova-client-1.1.0.jar.

Nova UI final build trigger.
